TRAFFIC JUNCTION SIMULATOR
Files: index.html, index.css, index.js
Run: open index.html in a browser, or use Live Server in VS Code/Antigravity. No backend or install required.

Features:
- Canvas top-down four-way intersection
- Adjustable spawn rate and fixed green duration
- Fixed and adaptive signal modes
- Cars wait at red, queue with spacing, and only one direction enters at a time
- Live passed, wait, queue and throughput stats; per-direction queue cards
- Pause, resume and reset
- Emergency corridor demo
- Fixed timing baseline comparison estimate

Note: This is an educational visual model, not a validated traffic engineering simulator. Adaptive/fixed comparison uses an independent illustrative baseline run.
